# YouTube Playlist Duration

YouTube の再生リストに、合計再生時間と再生中の位置からの残り時間を表示する、シンプルな Chrome / Microsoft Edge 拡張機能です。

## 主な機能

- 再生リストページ（`/playlist`）で、読み込み済み動画の合計再生時間を表示
- 再生リスト付き視聴ページ（`/watch?...&list=...`）で、現在の動画以降の残り時間を表示
- 現在位置、残り本数、合計時間をひと目で確認
- フルスクリーン再生中は表示を自動的に隠す
- YouTube 内のページ遷移や、遅れて読み込まれた動画にも自動追従
- YouTube へのサイトアクセス以外の追加権限なし。閲覧データの保存や外部送信なし

## インストール方法

この拡張機能は Chrome ウェブストア等には公開していないため、開発者モードで読み込みます。

1. このリポジトリを任意の場所に配置します。
2. Chrome の場合は `chrome://extensions/`、Edge の場合は `edge://extensions/` を開きます。
3. 「デベロッパー モード」または「開発者モード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を選びます。
5. `manifest.json` があるこのディレクトリを指定します。
6. YouTube のタブを再読み込みします。

## 使い方

YouTube で再生リストページ、または再生リストから動画を開くと、画面右下に時間が表示されます。

- **合計再生時間**: 現在 DOM に読み込まれている動画の長さの合計
- **残り時間**: 再生中の動画を含め、それ以降に読み込まれている動画の長さの合計

表示が更新されない場合は、YouTube のタブを一度再読み込みしてください。拡張機能を更新した場合も、既に開いている YouTube タブの再読み込みが必要です。

## 制限事項

- YouTube は長い再生リストを段階的に読み込むため、まだページに読み込まれていない動画は計算に含まれません。スクロールして動画が読み込まれると表示も更新されます。
- 非公開、削除済み、ライブ配信など、再生時間を取得できない項目は合計時間に含まれません。取得状況はバッジの「時間を取得済み」表示で確認できます。
- 「残り時間」は現在の動画の全尺を含みます。動画内で既に経過した時間は差し引きません。
- YouTube 側の画面構造が変更された場合、一時的に時間を取得できなくなる可能性があります。

## プライバシー

この拡張機能は YouTube ページ上の表示内容だけを参照します。データの保存、解析サービスの利用、外部サーバーへの通信は行いません。
